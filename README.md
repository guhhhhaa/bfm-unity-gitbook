#### SCP-2264（阿拉卡达迷城）概述

**1. ‌基础信息‌‌1**

* ‌**编号**‌：SCP-2264
* ‌**分级**‌：Safe
* ‌**类型**‌：超维度空间
* ‌**别名**‌：阿拉卡达之城、无尽螺旋形多元宇宙中心
* ‌**地理位置**‌：通过伦敦塔马丁塔底部的密室铁门（SCP-2264-A）进入‌1。

**2. ‌特殊收容措施‌‌1**

* 与英国政府合作封锁原入口，仅允许授权人员通过新建秘密通道进入SCP-2264-A。
* 定期检查炼金术仪器（坩埚、釜等）的异常活性，防止未经许可的仪式触发。

**3. ‌描述‌‌12**

* ‌**SCP-2264-A**‌：\
  位于伦敦塔的异常铁门，需通过特定炼金术仪式开启，与16世纪炼金术师亨利·珀西（“巫师伯爵”）及其合作者约翰·迪伊（伊丽莎白女王的占星师）相关。
* ‌**SCP-2264-B**‌：\
  门后的超维空间，作为多元宇宙交汇点，允许不同维度、法则的生物在此交流与贸易。其核心由至高神性“缢王”统治，四名领主分管四种颜色区域‌2。

**4. ‌历史背景‌‌1**

* 由亨利·珀西主导的团体“黑夜派”在囚禁期间秘密建造，融合炼金术与秘法。
* 推测其设计意图为建立“乌有之乡”，突破现实法则限制。

**5. ‌关联至高神性‌‌25**

* ‌**缢王（The Hanged King）**&#x200C;：
  * 阿拉卡达的统治者，表现为“神明形状的空洞”，被描述为“在提线上极乐窒息的暴君”‌2。
  * 与深红之王存在炼金术层面的同源性，通过阿拉卡达的力量抵御深红之王的入侵‌5。
* ‌**其他关联实体**‌：\
  阿拉卡达大使（秘术师）及四色领主，负责维护该空间的异常秩序。

* ‌**符号解释**‌：
  * ΩΩ：可数无限序数集合，代表多元宇宙的基数。
  * ZpαZpα​：每个宇宙的局部有限域（pp 为素数，随宇宙法则动态变化）。
